# 独立关注模块

- 入口：经典布局顶部“我的关注”、工作台侧栏“关注”、学习布局顶部“我的关注”。
- 地址：`#following`，兼容旧的 `#z-follow`；支持 `#following?tab=au&name=Patrick+Rodrigues` 和 `tab=jo`。
- 页面只展示关注工作区；返回后恢复原布局、检索条件和滚动位置。浏览器前进、后退也支持。
- 左侧为关注作者/期刊及全库姓名/期刊搜索，右侧为所选对象的全部库内文献。每页 20/50/100 篇，支持关键词、年份/被引排序。
- 文献支持摘要预览、完整摘要展开、收藏和完整阅读器。工作台进入的关注页面也使用弹窗阅读器，避免阅读器藏在被隐藏的工作台里。
- 继续使用原 `litdb-follows` 个人存储字段，无迁移、无云同步。取消关注不删除论文；回收站仍可从文献库访问。
- 姓名按规范化全名匹配，不做姓名子串扩展。没有作者唯一 ID 时无法保证消除同名歧义，界面提示结合机构核对。“全部”仅指本数据库已收录、未被本地隐藏的记录。
- 索引首次需要时建立并复用；不为每位关注作者预渲染文献，也不依赖当前主库筛选状态。

回归：12 篇作者完整显示、45 篇跨页可达、期刊切换、隐藏记录计数、取消关注、深链接、阅读器，以及经典/工作台返回。浏览器另以合成数据检查桌面、390px 手机宽度、完整摘要和深色模式；预览截图不代表真实论文内容。

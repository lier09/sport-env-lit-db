# 每日新增口径

网页只显示北京时间今天的新入库增量记录；今日无记录时显示空状态，不回退到昨天或近七天。顶栏和统计区使用同一数量。打开页面跨过北京时间零点后，一分钟内刷新当天展示。

需要文献或 `DAILY_NEW[YYYY-MM-DD]` 条目带有：

```json
{"id":"...","ingest_kind":"incremental","ingested_at":"2026-10-11T06:16:00+08:00"}
```

`ingested_at` 是真正写入总库的时间，不是论文发表日期。历史检索、手工回填、摘要/机构补全、标签修正和恢复记录不能标为 `incremental`。没有来源标记的旧记录不显示为今日新增，不能推测其任务来源。

来源端修正版 `daily_update.py` 为默认增量新增写入上述字段；`--full`、`--dissertation`、`--backfill` 及显式 `--from/--to` 时间窗口属于历史/专项任务，不写每日新增。已有记录的更新也不写入。当天多批记录合并并按 ID 去重。不要用全量结果覆盖当天增量列表。

来源环境须合并脚本修改，并在生成分片时保留 `ingest_kind`、`ingested_at`；这两个字段不能被压缩字段白名单去掉。网页也可直接从带标记的论文分片提取今日记录，无须依赖内联 DAILY_NEW 更新。不要为了让今日列表非空而给整个现有库补上今日时间戳。

完整数据和上传环境不在此仓库；本仓库提交只完成前端展示。数据端是否启用标记必须另行确认。
